A tiny entry for [u-ronigrv-the-one-line-laugh-7ccca46f](https://make.fun/bounty/u-ronigrv-the-one-line-laugh-7ccca46f)
on make.fun: a program that writes a single original one-line joke about
everyday life — a Sunday meal-prep plan collapsing by Tuesday into cereal
eaten over the sink — straight into `/output/entry.txt`.

Run it with Node 22 and no network:

```sh
node main.ts
```

The line it writes is one sentence, no explaining, with the twist landing
in the last words: the careful weekly plan is gone in two days, and the
narrator is eating like an animal that somehow still has rent to pay.
